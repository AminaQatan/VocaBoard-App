VOCABOARD - FULL BACKUP
=======================
Developed by: Ms. Amina Qatan
Version 1.7.2 - backup made 3 November 2026 (bright look, TV remote, new stickers)

WHAT IS IN THIS FOLDER
----------------------
1 - Website files (upload to GitHub)
    The finished app. These are the files in your GitHub repository
    VocaBoard-App (index.html, sw.js, manifest.webmanifest, the icons
    folder and the avatars folder). To restore the website, upload
    everything inside this folder to the repository.
    Your Google Apps Script link for the student QR codes is already
    built into index.html.

2 - Google Apps Script
    Code.gs: the script in your Smart Tech Attendance Google Sheet
    (Extensions > Apps Script). It saves attendance and receives the
    students' answers for Poll, Idea wall, Brainstorm and Exit ticket.
    You only need it again if you make a new Google Sheet.

3 - Source code (for future changes)
    The original files the app is built from (src folder, build.py,
    icons, avatars). Keep these so the app can be changed or updated
    later: "python3 build.py" rebuilds the website files.
    HOW-TO-INSTALL.txt explains installing VocaBoard on smart boards,
    laptops, tablets and phones.
